# Emerging Technologies Assessment

## Overview

This repository contains a Jupyter notebook exploring the difference between classical and quantum algorithms, with a focus on the **Deutsch–Jozsa algorithm**, one of the earliest demonstrations that quantum computers can solve certain problems exponentially faster than any classical approach.

The notebook progresses through five problems: generating Boolean functions, measuring the classical cost of testing them, building quantum oracles in Qiskit, implementing Deutsch's single-bit algorithm, and finally scaling up to the full Deutsch–Jozsa algorithm for 4-bit functions.

## Problems

1. **Generating Random Boolean Functions** — Implements `random_constant_balanced`, a function that returns a random 4-input Boolean function that is either constant or balanced.

2. **Classical Testing for Function Type** — Implements `determine_constant_balanced` and analyses the classical query cost. For 4-bit functions, up to 9 calls are needed in the worst case.

3. **Quantum Oracles** — Builds the four single-input quantum oracles (constant-0, constant-1, identity, NOT) in Qiskit using phase kickback, with circuit diagrams saved to `/img`.

4. **Deutsch's Algorithm with Qiskit** — Implements the full single-qubit Deutsch circuit and demonstrates it against all four oracles, explaining how quantum interference determines the function type in a single query.

5. **Scaling to the Deutsch–Jozsa Algorithm** — Extends the approach to 4-bit functions using `build_dj_oracle` and `deutsch_jozsa`, demonstrating 1 quantum query vs 9 classical queries.

## Setup Instructions

### Requirements

- Python 3.8 or higher
- pip

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/StevenDerrig/Emerging-Technologies-Assessment
   cd Emerging-Technologies-Assessment
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Launch the notebook**
   ```bash
   jupyter notebook problems.ipynb
   ```

Run all cells sequentially using **Shift + Enter** or select **Run All** from the Cell menu. The `/img` folder will be created and populated automatically when the notebook runs.
